Doce juegos educativos hechos con IA, Python y Flask. Nacieron para mi hija y los
comparto con cualquier niño que quiera usarlos: **sin cuentas, sin anuncios y sin
publicidad**. Leer capítulo a capítulo, matemáticas, sopas de letras, las
comunidades autónomas, el reloj analógico, el sistema solar, lógica, cocina para
monstruos, pociones de colores, programar un robot, componer música y una batalla
de unicornios a dos jugadores.
